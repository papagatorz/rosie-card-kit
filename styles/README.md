# Your saved styles

Put your own style files here. `fill.py --style NAME` reads `styles/NAME.json`, and `styles/default.json`, if you create it, is applied to every card (skip it with `--no-default-style`). See "Customize your card" in the main README and the examples in `examples/`.

Files in this folder are ignored by git (they may name real people or point at personal photos), except this README.
